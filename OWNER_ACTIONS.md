Твои задачи как единственного разработчика / капитана
Первые 10 минут
- [ ] Включить Codex в папке существующего MVP v2; скопировать сюда CODEX_MISSION.md и дать Codex команду прочитать и исполнять его поэтапно.
- [ ] Сохранить резервную копию всей папки проекта, включая файл текущей SQLite, без публикации.
- [ ] Проверить состояние Git и убедиться, что .env, .venv, .sqlite3 находятся в .gitignore. Если нет GitHub, локальный git достаточен для начала.
- [ ] Проверить, в проекте v2 или в v1 запущен работающий сервер. Если нет — не терять рабочую версию, прислать Codex фактический путь к папке.
В следующие 20 минут — одновременно с Codex
- [ ] В личном кабинете организаторов найти адрес API стенда «Регистратура» и /docs или /openapi.json; скачать спецификацию.
- [ ] Найти настоящий Excel расписания, регламент, CSV и список вымышленных пациентов/разрешённые тестовые идентификаторы.
- [ ] Проверить вход в админку МИС и где видны созданные записи / журнал API.
- [ ] Проверить, есть ли токен API. Не передавать его в переписки, GitHub или промпт Codex; хранить в .env или переменной окружения, без вывода значения.
- [ ] Уточнить предел времени сдачи, формат ссылки на решение, кто имеет доступ и нужно ли отдельное видео.
Тестируй сам после каждой поставки от Codex
- [ ] Работающий текстовый сценарий с новой записью.
- [ ] Включить TTS, убедиться, что в браузере слышна РУССКАЯ речь (не просто создан WAV-файл).
- [ ] Три фразы ASR на русском с датами и временем, вручную проверить транскрипцию и latency.
- [ ] Проверить невозможность записать в прошлое и отсутствие повторной записи в занятый слот.
- [ ] «Нет, я хотел в понедельник» — ассистент должен менять дату, не создавать запись.
- [ ] «У меня сильная боль» и «Соедините с оператором» — нет медсовета и ложного сообщения о настоящем переводе звонка.
- [ ] При появлении live API разрешить ровно одну синтетическую операцию записи, проверить ID и фактическое появление в админке.
- [ ] Во всех сообщениях для жюри указывать статус: mock или live.
Порог принятия решений
- 15–20 минут без результата TTS: останавливаем сложную установку, сохраняем рабочий текст.
- Если API и Excel недоступны: пишем организаторам и концентрируемся на локальном голосовом MVP, но не объявляем интеграцию выполненной.
- Если текстовый сценарий перестал работать: останавливаем добавление функций, восстанавливаем предыдущую рабочую версию.
- Не позже чем за 30 минут до отправки: заморозка фич, тесты, README, доступная жюри ссылка/видео, фактическая отправка.
Что прислать помощнику для следующего шага
- Ссылку на общедоступную страницу API /docs либо файл OpenAPI JSON/YAML (без токена).
- Excel/CSV и документы кейса, если содержат только разрешённые тестовые данные; иначе обезличенный образец структуры.
- Краткий вывод Codex: тесты, список изменённых файлов, блокеры, длительность ASR/TTS.
- Не передавать API-токен, реальные ФИО/даты рождения/телефоны пациентов и другие секреты.
