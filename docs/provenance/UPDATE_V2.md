# MVP v2 — улучшенные даты, время, UX и скорость

## Обновление без потери локальных записей

1. Закройте запущенный сервер `Ctrl+C`, закройте вкладку демо.
2. На всякий случай скопируйте папку старой версии в резервную.
3. **Для сохранения своей базы** скопируйте из ZIP v2 в существующую папку только:
   - `app.py`
   - `core/dialog.py`, `core/parse_ru.py`, `core/service.py`, `core/voice.py`
   - `tests/test_russian.py`
   - `requirements-voice.txt`
   - `start_windows.bat`
4. Не заменяйте и не удаляйте `data/demo.sqlite3`: это ваша локальная база. `data/synthetic_schedule.xlsx` тоже можно оставить прежней.
5. Запустите `start_windows.bat` и откройте `http://127.0.0.1:7860`.

**Альтернатива:** распакуйте v2 в новую папку и запустите `start_windows.bat`. Это создаст новую чистую локальную базу имитации, не затрагивая старую.

## Что улучшено

- Даты: `15 октября`, `пятнадцатого октября`, `в пятницу`, `на следующей неделе в понедельник`, ISO и `ДД.ММ.ГГГГ`.
- Время: `девять тридцать`, `в два часа дня`, `14:00`, `в половине десятого`, `14 часов 30 минут`; ответы принимаются **только если найден подходящий свободный слот**.
- После указания врача выводятся ближайшие доступные даты из Excel; после дня — список реальных свободных времен.
- Интерфейс содержит dropdown с доступными временами, из которого можно выбрать слот без ошибки ASR.
- Голос: аудио сначала распознаётся и отображается в редактируемом поле, затем пациент нажимает «отправить». Время ASR показывается для замера.
- Для ускорения Windows SAPI по умолчанию выключен; его можно включить флажком «Озвучивать ответы». Качество голоса всё ещё Windows SAPI, не Piper.
- faster-whisper `beam_size=1`, короткий контекст для слов регистратуры, pinned `av<19`.
- 13 автоматических тестов.

## Ограничения

- **МИС только MOCK, Excel синтетический!** Нельзя заявлять, что работает интеграция в систему организаторов.
- Никакая LLM не подключена. Диалоговый автомат предсказуемый, но ограниченный.
- Даты рождения прописью с полностью произнесённым годом пока не поддерживаются; вводите цифровой формат.
- Настоящее расписание и пациенты должны поступить от организаторов. Исходные примеры, API и токен пока не получены.
- Перевод на живого оператора в веб-прототипе только имитируется.
- Проверка ASR после обновления должна быть выполнена на вашей Windows-машине. Автоматические тесты в текущем окружении проверяют только код и сценарии.

## Что проверить

1. `Запишите к терапевту в пятницу` — предлагается время только из расписания.
2. Ответ `девять тридцать` — выбирается `09:30` при наличии этого времени; иначе отказ.
3. Новый диалог, `Запишите к терапевту на 15 октября` — если день прошёл или расписания нет, должен появиться понятный ответ и ближайшие альтернативы.
4. Сделайте короткое аудио, нажмите «Распознать речь», при необходимости исправьте текст, отправьте.
5. После выбора ФИО, даты рождения и `да` обновите таблицу — запись появляется; повторный слот не доступен.

## Главный следующий этап

Получить у организаторов OpenAPI, вымышленных пациентов, Excel расписания, доступ к админке. Без них рабочая имитация не превратится в реальный сценарий чекпоинта.
