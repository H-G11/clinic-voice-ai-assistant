# ASR: измерения на аудио и ручная проверка

> Historical author-supplied record. Performance, test counts and device checks below were not reproduced in the 2026-10-24 audit. See [current verification](verification.md) for actual results and blockers.

Измерено 20 WAV, синтезированных локальным Piper из [размеченных фраз](../tests/asr_eval_20.csv).
Это **синтетическая проверка**, а не измеренная точность человеческого голоса или микрофона пользователя.
Модель действительно обрабатывала аудио; затем парсер извлекал специальность/дату/время/ФИО/дату рождения/согласие/операторский запрос.
Все 20 эталонных текстов отдельно проверены на соответствие размеченному полю.

| Конфигурация, CPU int8, ru | Верное поле | WER¹ | Медиана ASR | p95² | Загрузка³ |
|---|---:|---:|---:|---:|---:|
| Исходная base, beam 1, VAD, прежний prompt | 13/20 | 37,1% | 0,87 с | 1,05 с | 1,07 с |
| base, beam 1, VAD с padding 500 мс, общий prompt | 12/20 | 38,7% | 0,89 с | 4,41 с | 1,22 с |
| base, beam 5, без VAD, общий prompt | 13/20 | 37,1% | 0,93 с | 1,09 с | 1,23 с |
| small, beam 5, без VAD, общий prompt | 17/20 | 33,9% | 2,98 с | 3,09 с | 2,25 с |

¹ Орфографический WER учитывает различия цифр/слов; его нельзя приравнивать к ошибке смыслового поля.
² На 20 примерах используемый эмпирический индекс p95 попадает в максимум; это нестабильная оценка хвоста.
³ Сумма времени ленивой загрузки по прогону, почти полностью первый вызов; в медиану ASR загрузка не входит.
Прогоны выполнены на той же машине; часть сопровождалась другой локальной работой. Это ориентир задержки, не изолированный performance-тест.
Подробные синтетические транскрипты, ошибки и тайминги: [asr-evidence.json](asr-evidence.json).

Выбор для UI: уже скачанная **small / CPU int8 / beam 5 / VAD off**, с быстрым профилем base.
На этом корпусе small дала на четыре верных поля больше исходной base ценой примерно 2,1 с дополнительного распознавания.
Смена одного prompt/VAD улучшения не дала; её нельзя объявлять решением проблемы.
Ошибки остаются, поэтому ФИО/дата/время проверяются человеком и доступны ручные поля.
Отдельный GPU-пробный запуск запросил CUDA, но инференс перешёл на CPU после ошибки CUDA.
Наличие RTX 4060 само по себе не доказывает GPU-инференс; CUDA/cuDNN/драйверы не переустанавливались.

Ранее по умолчанию использовалась base, CPU, int8, beam=1, language=ru, VAD=True.
Новый код декодирует PyAV/faster-whisper в 16 000 Гц, моно без ручной обрезки.
Диагностика показывает исходную частоту/каналы, длительность, долю предельной амплитуды и энергию у краёв.
В корпусе Piper — 22 050 Гц, моно. Отдельный тест проверяет 48 000 Гц стерео → 16 000 Гц моно с сохранением секунды звука.
Энергия у границы означает риск обрезки, но **не доказывает** потерю слогов: оригинальный микрофонный сигнал не предоставлен.
Задержки разделены на загрузку модели, декодирование аудио и распознавание.

Воспроизведение измерений из PowerShell, в корне проекта:

```powershell
.\.venv\Scripts\python.exe scripts/asr_benchmark.py --generate --model base --beam 1 --vad 1 --legacy-decode --tag original_base_cpu_b1_vad
.\.venv\Scripts\python.exe scripts/asr_benchmark.py --model base --beam 5 --vad 0 --tag base_cpu_b5_no_vad
.\.venv\Scripts\python.exe scripts/asr_benchmark.py --model data/asr_models/small --beam 5 --vad 0 --tag small_cpu_b5_no_vad
```

Модели должны уже находиться локально: benchmark запрещает скачивание во время инференса.
small загружена отдельной разрешённой операцией только в проект; аудио наружу не отправлялось.
UI не загружает модели при запуске. Переменные ASR_MODEL/DEVICE/BEAM_SIZE/VAD переопределяют профиль, ASR_LOCAL_ONLY=1 задан по умолчанию.

Для **человеческой** проверки запишите все 20 фраз своим микрофоном в `data/asr_eval/human/01.wav` … `20.wav`.
Произнесите только текст из CSV, без настоящих персональных данных, без исправления результата вручную перед замером.
Оставляйте небольшую паузу до и после фразы. Прогоны обеих моделей выполняйте по одним и тем же файлам:

```powershell
.\.venv\Scripts\python.exe scripts/asr_benchmark.py --audio-dir data/asr_eval/human --source-kind human_recorded --model base --beam 1 --vad 1 --legacy-decode --tag human_base
.\.venv\Scripts\python.exe scripts/asr_benchmark.py --audio-dir data/asr_eval/human --source-kind human_recorded --model data/asr_models/small --beam 5 --vad 0 --tag human_small
```

Результаты сохраняются локально в игнорируемой `data/asr_eval/`. Сравнивайте field_correct/samples и медиану/p95 отдельно.
До такого прогона вывод о качестве на живом голосе остаётся открытым.
