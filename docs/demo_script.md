# Демо исправленного сценария — локальный MOCK

Если открыт старый сервер, нажмите Ctrl+C в его окне, затем запустите `start_windows.bat`.
Откройте http://127.0.0.1:7860. Отдельную форму подготовки пациента открывать не требуется.
Во всех примерах используйте только вымышленные данные.

1. «Запишите к хирургу» → «Тестов Иван Сергеевич» → «01.01.1990».
   Если карточки нет, бот покажет ФИО/дату и предложит создать вымышленную карточку.
   Нажмите «Да, создать вымышленную карточку». Если карточка уже найдена, этот шаг пропускается.
2. Выберите врача из предложений/списка Excel, затем одну из доступных дат и свободное время.
   Можно написать «утром», «после обеда», «другое время» и выбрать точный слот справа.
3. Проверьте сводку: вымышленные ФИО/дата рождения, врач, дата/время, кабинет.
   Нажмите кнопку подтверждения либо введите «да» в текстовом поле. Это отдельное согласие на запись.
   Покажите ID симулятора и обновите таблицу: занятый слот больше недоступен.
4. «Статус записи» → те же ФИО/дата рождения: «Запланирована».
5. «Перенести запись» → идентификация → при нескольких записях выберите нужную → новые дата/время → подтверждение.
   ID визита API-симулятора сохраняется. Снова проверьте статус: время изменилось.
6. «Отменить запись» → идентификация → на предложение переноса ответьте «отменить» → подтвердите отмену.
   «Статус записи» → идентификация: «Отменена». Освобождённый слот снова доступен.
7. «Оператор» → откройте внизу «Административный раздел — очередь оператору» → обновите очередь.
   Видны причина, P3, собранные сведения, «Требуется оператор». Жалоба даёт P2.
   Без идентификации заявка локальная; с подтверждённой карточкой используется /escalations симулятора.
   Телефонного соединения нет. «Давит в груди» немедленно выдаёт инструкцию 103/112 и создаёт P1.
8. «Проверить голос» → ▶. Piper слышен по ручной проверке пользователя; HTTP-доставка PCM проверяется автоматически.

Голосовой ввод: запишите короткую фразу → остановите запись → получите ответ.
Если текст ошибочен, исправьте поле «Я услышал» и отправьте исправление.
Профиль «Точнее: small» использует локальную small; «Быстрее: base» — кэшированную base.
Диагностика показывает модель, устройство, beam/VAD, частоту/каналы и три отдельных тайминга.
Важное «да» из ASR само операцию не выполняет: подтвердите показанные данные кнопкой/ручным текстом.
При ошибках ФИО/даты раскройте «Если голос ошибается: ввести данные вручную».
Дата рождения — ДД.ММ.ГГГГ; время выбирается из фактически свободных слотов справа.

Врач/кабинет/слоты берутся из исходного Excel: 85 врачей, 136 973 слота, GMT+4.
Участки и направления отсутствуют в исходных данных; для общего демо выбирайте хирурга.
Расписание ограничено ближайшими 14 днями и заканчивается фактически 30.12.2026.

Доказательство текущего пути: `scripts/check_ui_e2e.py` → [ui-evidence.json](ui-evidence.json).
Прогон начинает с пустых таблиц пациентов в изолированной копии Excel-базы, основной базы не касается.
Фиксированное 15.10.2026 09:00 применяется только в тестовом прогоне.
Старый `demo-evidence.json` — архив предыдущего сценария с подготовленной карточкой.
Свободные фразы и запись своего benchmark: [voice-quality.md](voice-quality.md).
Попробуйте «Мне бы к хирургу в пятницу после обеда», «Лучше после трёх», «А утром что-нибудь есть?»,
«Тогда второй вариант», «Нет, я сказал шестнадцатого, а не семнадцатого», «А какой кабинет?».
Замеры ASR на человеческих записях ещё нужно выполнить; без них улучшение живого голоса не заявляется.
Настоящий API, телефония, SMS, напоминания не подключены.
