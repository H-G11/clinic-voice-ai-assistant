# Локальная регистратура — описание для сдачи

> Historical author-supplied record. Performance, test counts and device checks below were not reproduced in the 2026-10-24 audit. See [current verification](verification.md) for actual results and blockers.

Локальный MVP с реальными исходными данными кейса клиники и адаптером под REST API
стенда; интеграционный тест живого стенда ожидает доступа. Все операции пока MOCK,
пациенты только синтетические. Excel сам описывает графики/статусы как данные хакатона.

**Работает и проверено:** потоковый импорт 85 врачей и 136973 слотов из предоставленного
Excel в отдельную SQLite. Используются фактические кабинеты/длительности/статусы,
календарь и недоступность; отсутствующие слоты не создаются. Горизонт 14 дней, сегодня
не менее 30 минут, GMT+4. Предыдущая база с записями сохранена.

Диалог идентифицирует синтетического пациента по ФИО/дате рождения, предлагает врача,
дату и свободный слот, подтверждает критичные поля. Если карточки нет, предлагает
отдельно подтвердить её создание прямо в разговоре и продолжает запись без сброса.
Реализованы запись, статус, перенос PATCH того же visit ID,
отмена, поиск/пагинация врачей. SQL блокирует дубли и вторую активную запись к специальности.
Таймаут мутации не повторяется; при неопределённом переносе удерживаются оба времени.

Регламент РГ-ТЕЛ-01 определяет экстренные флаги, FAQ, идентификацию, короткие реплики,
оператора и жалобы. Категория А получает инструкцию 103/112, категория Б — сотрудника
или 103 вне часов. Реального соединения/SIP нет: заявка появляется в административной
очереди с приоритетом, причиной и контекстом. Анонимно сохраняется локальный инцидент,
для проверенного синтетического клиента используется /escalations симулятора.
Участки/направления не известны и не подменяются вымышленными разрешениями.
FAQ содержит условные сведения регламента; перед реальным применением они требуют актуализации.

Русский Piper TTS выполняется локально на CPU: создан и проверен настоящий PCM WAV,
проверена доставка через HTTP-обработчик Gradio. Пользователь подтвердил слышимость.
Whisper ASR локален, транскрипт редактируется, тайминги раздельны. На 20 синтетических
Piper WAV: исходная base 13/20 важных полей, медиана 0,87 с; small 17/20, 2,98 с.
Это не измеренная точность человеческой речи. Small включена как локальный профиль,
base остаётся быстрым вариантом. Ручные поля и подтверждение защищают критические действия.

**API-совместимость:** симулятор исполняет документированные /api/v1 методы клиентов,
врачей, визитов и эскалаций с Bearer, пагинацией, командами и статусами. HTTP-fixture
проверяет ошибки/лимиты/таймауты. Реализован RealMIS, сопоставление Dxxx с числовыми ID
по ФИО+специальности, shared limiter 8/min, кэш врачей, запрет автоматического повтора POST.
MOCK IDs не используются для LIVE-изменений. Настоящий сервер не проверен; в его админке
записи не создавались. Фиктивные HTTP-тесты не доказывают интеграцию с организаторами.

**Историческая аналитика:** 17772 звонка, 3687 пропусков, пик 09:00 — 2414; 35470 приёмов,
4079 неявок. Доля неявок среди состоявшихся+неявок — около 13.09%, отмены исключены только
из этого знаменателя. Показаны часы с возможным отсутствием операторов. Экономика имеет
явные допущения; эффекта внедрения/KPI без измерения не заявляем.

Доказательства: docs/ui-evidence.json, docs/asr-evidence.json, tests/acceptance.md,
docs/progress.md. Аналитика: docs/insights.md и data/analysis/*.png. Демо локально:
start_windows.bat, http://127.0.0.1:7860. Публичное видео/ссылку готовит владелец.
Далее — ручной голосовой прогон, выдача URL/токена, сверка контрактов и одна явно
разрешённая синтетическая операция на настоящем стенде с проверкой внешнего ID/админки.
